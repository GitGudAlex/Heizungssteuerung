# Infos zum Quellcode

## GitLab Repository

Der vollständige Quellcode, alle Dokumentationen sowie sämtliche Änderungen und Versionen des Projekts können in unserem GitLab-Repository eingesehen werden.

[Heizungssteuerung Repository auf GitLab](https://gitlab.mi.hdm-stuttgart.de/tz023/heizungssteuerung)

## Änderungen und Beiträge

Alle Änderungen und Weiterentwicklungen des Projekts werden direkt im GitLab-Repository dokumentiert. Interessierte können dort den aktuellen Stand des Projekts einsehen, vergangene Änderungen nachvollziehen und sich aktiv an der Weiterentwicklung beteiligen.

Vielen Dank für Ihr Interesse an unserem Projekt!
